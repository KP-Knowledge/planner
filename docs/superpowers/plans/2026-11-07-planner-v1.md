# Planner v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Gantt-chart project planner with Keycloak login, Thai holidays, working-day scheduling, team colors, dark mode, deployable via Docker Compose on Dokploy.

**Architecture:** One Next.js 16 App Router app serves both UI and REST API (`src/app/api/**/route.ts`). Route handlers stay thin: auth check, Zod parse, call a service in `src/server/*` that takes a Drizzle `db` argument (real Postgres in prod, PGlite in tests). Date and scheduling logic lives in pure modules under `src/lib/` and runs on both client (drag preview) and server (authoritative cascade). The Gantt is hand-built React + SVG.

**Tech Stack:** Next.js 16.4, React 19, TypeScript strict, Tailwind CSS 4.3, next-themes 0.4, next-intl 4.14 (no locale routing, cookie-based), Auth.js `next-auth@5.0.0-beta.32`, Drizzle ORM 0.45 + drizzle-kit 0.31 + `pg`, Zod 4, TanStack Query 5, @dnd-kit/core 6 + @dnd-kit/sortable 10, date-holidays 3.38, Vitest 5, @electric-sql/pglite 0.5, Playwright 1.65, Postgres 18, Node 22, pnpm.

**Spec:** `docs/spec.md`

## Global Constraints

- Work on branch `feat/planner-v1`. Each task's "Checkpoint" step means: commit the task's changes with a Conventional Commits message. Never push.
- Next.js 16: auth guard lives in `src/proxy.ts` exporting `proxy` (not `middleware.ts`). Proxy runtime is nodejs.
- All calendar dates are `ISODate` strings `YYYY-MM-DD`. DB columns use `date("...", { mode: "string" })`. Never convert a stored date through `new Date()` local time.
- "Today" is computed in `Asia/Bangkok`.
- Saturday and Sunday are always non-working days.
- Task date range is inclusive: a 1-day task has `startDate === endDate`.
- Every `/api/*` route except `/api/auth/*` returns 401 JSON when there is no session.
- UI default locale `en`, second locale `th`, stored in cookie `locale`.
- Theme follows Instagantt palette (from instagantt.com CSS): primary `#4F46E5`, accent `#7C3AED`, text `#111827`, muted `#6B7280`, border `#E5E7EB`, surface `#F9FAFB`, success `#10B981`, warning `#F59E0B`, danger `#EF4444`. Font Inter. Dark mode via `class` strategy.
- Team color palette for the picker: `#4F46E5 #7C3AED #EC4899 #EF4444 #F97316 #F59E0B #10B981 #06B6D4 #6B7280`. Default task color when no team and no override: `#4F46E5`.
- Compose service names prefixed `planner-` (Dokploy DNS collision lesson).
- `date-holidays` TH has no Buddhist holidays from 2027 onward and no substitution days ever (verified on 3.38.0). UI must make adding them easy; do not try to compute lunar dates.

## Decisions taken in this plan (not in spec, confirm on review)

- Subtasks are one level deep. Parent task dates are independent of subtask dates (no roll-up).
- A task always has dates. New task defaults: start = today snapped to the next workday, 1 workday long.
- Adding or removing a holiday does not move existing tasks. Duration shown in the grid is recomputed. Auto-shift happens only when a task is edited.
- Permanent project delete is allowed only for archived projects.
- Concurrent edits: last write wins.

## Review Focus

1. Dragging a bar so its start lands on a weekend or holiday: start snaps to the next workday and the workday duration stays the same. Test in Task 3 (`moveTask snaps to workday`).
2. Creating a dependency that closes a cycle (A→B→C→A) returns 409 and nothing is saved. Test in Task 5 (`rejects cycle`).
3. Cascade through a chain where a successor of a successor also collides: every task downstream is pushed, and tasks that do not collide are untouched. Test in Task 3 (`cascade multi-level`).
4. Deleting a team used by tasks: those tasks fall back to the default color, no error. Test in Task 5 (`team delete nulls task teamId`).
5. Server clock near midnight UTC (e.g. 2026-04-12T18:30Z is already 04-13 in Bangkok): "today" line and new-task default use the Bangkok date. Test in Task 3 (`todayInBangkok`).
